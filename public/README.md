# דרך חתם סופר — אפליקציית תכנון משלוחים

זו אפליקציה אמיתית: התחברות עם סיסמה, מסד נתונים אמיתי, וחישוב מסלולים אמיתי (לא הדמיה). כדי שהיא תעבוד, היא צריכה לרוץ על שרת (לא כקובץ יחיד שנפתח בדפדפן) — יש לך שתי דרכים להריץ אותה, בלי צורך בידע טכני קודם.

---

## ⭐ העלאה לאוויר לצמיתות (מומלץ): Render + Neon — חינם, בלי כרטיס אשראי

התוצאה: כתובת קבועה כמו `https://derech-chatam-sofer.onrender.com` שעובדת מכל טלפון ומחשב, גם כשהמחשב שלך כבוי, והנתונים (משתמשים, לקוחות, מסלולים) נשמרים לצמיתות.

### שלב 1 — מסד נתונים חינמי ב-Neon (5 דקות)
1. היכנס ל-**neon.tech** ← Sign up (אפשר עם חשבון Google).
2. צור פרויקט חדש (Create project). שם: מה שתרצה. אזור (Region): **AWS Europe (Frankfurt)**.
3. במסך שנפתח לחץ **Connect** והעתק את ה-**Connection string** — שורה שמתחילה ב-`postgresql://...`. שמור אותה בצד.

### שלב 2 — העלאת הקוד ל-GitHub (5 דקות)
1. היכנס ל-**github.com** וצור חשבון (אם אין לך).
2. למעלה מימין: **+** ← **New repository**. שם: `derech-chatam-sofer`. אפשר לסמן **Private**. לחץ **Create repository**.
3. בעמוד שנפתח לחץ על הקישור **uploading an existing file**.
4. חלץ את קובץ ה-ZIP במחשב, וגרור לחלון של GitHub את **כל מה שבתוך התיקייה** (כולל התיקייה `public` והקובץ `render.yaml`).
5. למטה לחץ **Commit changes**.

### שלב 3 — הפעלה ב-Render (5 דקות)
1. היכנס ל-**render.com** ← **Get Started** ← הירשם עם **GitHub** (ואשר את הגישה).
2. לחץ **New +** ← **Blueprint**, ובחר את המאגר `derech-chatam-sofer` (אם הוא לא מופיע — לחץ "Configure account" ותן ל-Render גישה אליו).
3. Render יקרא את ההגדרות לבד ויבקש ממך ערך אחד: **DATABASE_URL** — הדבק שם את השורה מ-Neon.
4. לחץ **Apply** / **Deploy**. אחרי 2–4 דקות יופיע סטטוס **Live** וכתובת האתר שלך למעלה.
5. היכנס לכתובת, לחץ "הרשמה" — וזהו, האפליקציה באוויר. 🎉

**כדאי לדעת:**
- בתוכנית החינמית, אם אף אחד לא נכנס 15 דקות האתר "נרדם", והכניסה הבאה לוקחת כחצי דקה עד דקה. אחר כך הכול מהיר.
- עדכון גרסה: מעלים שוב את הקבצים ששונו ל-GitHub (Add file ← Upload files), ו-Render מעדכן את האתר לבד תוך כמה דקות. הנתונים לא נפגעים.
- מפתחות אופציונליים (RESEND_API_KEY, OPENCAGE_API_KEY וכו') מוסיפים ב-Render תחת **Environment**.
- אם אחד האתרים חסום אצלך בסינון (NetFree), אפשר לבקש מהם לפתוח אותו.

## דרך א' (הכי פשוטה): הרצה בענן דרך Replit — בלי להתקין שום דבר

1. היכנס לאתר **replit.com** וצור חשבון חינמי (אפשר עם Google).
2. לחץ על **Create Repl** (או "+ צור").
3. בחר באפשרות **Import from ZIP** / **Upload folder** (בממשק העדכני זה מופיע תחת "Import code or design" → "Upload files/folder").
4. העלה את כל התיקייה הזו (או את קובץ ה-ZIP שקיבלת).
5. Replit יזהה שזו אפליקציית Node.js. לחץ על הכפתור הירוק **Run**.
6. אחרי כמה שניות תיפתח למעלה חלונית עם כתובת אינטרנט (URL) — זו הכתובת הקבועה של האפליקציה שלך. אפשר לפתוח אותה גם מהטלפון.
7. זהו. היכנס לכתובת, לחץ "הרשמה", וצור את המשתמש הראשון שלך.

**חשוב:** בתוכנית החינמית של Replit האפליקציה עלולה "להירדם" אחרי זמן ללא שימוש, ותתעורר שוב אוטומטית כשתיכנס אליה (ייקח כמה שניות). אם תרצה שהיא תהיה זמינה תמיד, יש ב-Replit שדרוג בתשלום ("Always On"), או שאפשר לעבור לחלופה כמו Render.com שמציעה גם היא שכבה חינמית דומה.

## דרך ב': הרצה על המחשב שלך

1. התקן **Node.js** (חינם): כנס ל-**nodejs.org** והורד את הגרסה המומלצת (LTS). התקנה רגילה כמו כל תוכנה.
2. פתח את התיקייה הזו במחשב שלך.
3. **Windows:** לחץ פעמיים על הקובץ `start-windows.bat`.
   **Mac:** לחץ פעמיים על הקובץ `start-mac.command` (בפעם הראשונה ייתכן שתצטרך לאשר הרשאת הרצה דרך "העדפות מערכת ← פרטיות ואבטחה").
4. ייפתח חלון שחור (טרמינל) שמתקין את מה שצריך ומפעיל את השרת.
5. פתח דפדפן וגלוש לכתובת: **http://localhost:3000**
6. לחץ "הרשמה" וצור את המשתמש הראשון שלך.

הערה: כשהמחשב שלך כבוי או שהחלון השחור נסגר, האפליקציה לא זמינה — זה מתאים לשימוש אישי/בדיקה. לשימוש יומיומי מהטלפון בזמן נהיגה, דרך א' (Replit) עדיפה כי היא נשארת זמינה גם כשהמחשב שלך כבוי.

## מה בנוי כאן בפועל

- **התחברות אמיתית**: הרשמה, התחברות, יציאה, ושחזור סיסמה. הסיסמאות מוצפנות (bcrypt) ולא נשמרות כטקסט גלוי.
- **מסד נתונים אמיתי**: כל המשתמשים, הלקוחות הקבועים, המסלולים השמורים וההיסטוריה נשמרים ב-Postgres כשהאפליקציה רצה בענן (ראו למעלה), או בקובץ `db.json` בתיקיית הבית כשהיא רצה על המחשב שלך ונשאר גם אחרי כיבוי והפעלה מחדש. כל משתמש רואה רק את הנתונים שלו.
- **חיפוש כתובות וחישוב מסלול אמיתיים**: השרת פונה בפועל ל-OpenStreetMap (לזיהוי כתובות) ול-OSRM (לחישוב מרחקים, זמנים ומסלול על הכבישים בפועל), ומריץ בעצמו אלגוריתם אופטימיזציה (שכן קרוב + שיפור 2-opt) כדי לקבוע את סדר העצירות הטוב ביותר.
- **שחזור סיסמה**: כברירת מחדל, אם לא הגדרת שירות שליחת מיילים, קישור האיפוס פשוט מוצג לך על המסך (זה עובד באמת, רק בלי מייל אמיתי). אם תרצה שליחת מייל אמיתית — פתח חשבון חינמי ב-**resend.com**, קח משם מפתח API, והדבק אותו בקובץ `.env` (העתק את `.env.example` לקובץ בשם `.env` ומלא שם `RESEND_API_KEY`). ב-Replit אפשר להגדיר את זה דרך "Secrets" בתפריט הצד במקום קובץ `.env`.
- **זיהוי כתובות מדויק יותר, בחינם וללא כרטיס אשראי בכלל**: אפשר להוסיף **OpenCage** כניסיון נוסף אוטומטי (2,500 חיפושים ביום בחינם, רק הרשמה עם אימייל ב-**opencagedata.com**, בלי כרטיס אשראי). מדביקים את המפתח כ-`OPENCAGE_API_KEY` בקובץ `.env`. זה לא תמיד ימצא כתובת שה-OpenStreetMap הרגיל פספס (שני השירותים די דומים בבסיס הנתונים), אבל זה ניסיון חינמי נוסף בלי שום סיכון.
- **קריאת קובצי PDF בעברית בצורה מדויקת (מומלץ מאוד)**: קבצי PDF בעברית עם טבלאות (כמו רשימת משלוחים) נוטים לצאת מבולגנים בחילוץ טקסט רגיל. האפליקציה יודעת להשתמש בכלי בשם **Poppler** שפותר את זה כמעט לגמרי — אם הוא לא מותקן, היא עדיין תעבוד אבל בדיוק נמוך יותר (וללא הפרדה של הערות מהכתובת). ברוב שירותי האירוח בענן (Replit, Render) הוא כבר מותקן אוטומטית ואין צורך לעשות כלום. **אם מריצים מקומית ב-Windows** וכתובות מקובצי PDF יוצאות מבולגנות:
  1. הורידו את הגרסה האחרונה של Poppler for Windows מ-**github.com/oschwartz10612/poppler-windows/releases** (קובץ ZIP).
  2. חלצו אותו לתיקייה קבועה כלשהי, למשל `C:\poppler`.
  3. בתוך התיקייה שחילצתם, אתרו את תיקיית `bin` שבתוכה קובץ `pdftotext.exe`.
  4. בקובץ `.env` שלכם, הוסיפו שורה: `PATH_EXTRA=C:\poppler\Library\bin` (התאימו לנתיב האמיתי אצלכם עד לתיקיית ה-bin).
  5. הפעילו מחדש את האפליקציה.
  גם בלי זה, כל כתובת שלא זוהתה בביטחון מלא תסומן בכתום כדי שתדעו לבדוק אותה ידנית — שום דבר לא "נעלם" בשקט.
- **HERE Maps (דורש כרטיס אשראי, נכון לעדכון האחרון שלהם)**: HERE נוטים להיות מדויקים יותר מחוץ לארה"ב, כולל ישראל — אבל החל מאוגוסט 2025 הם ביטלו את התוכנית שלא דרשה כרטיס אשראי. אם זה לא מפריע לך (לא תחויב כל עוד נשארים במכסה החינמית), אפשר להירשם ב-**developer.here.com** ולהדביק את המפתח כ-`HERE_API_KEY`.
- **מפת Google Maps (אופציונלי, דורש כרטיס אשראי)**: כברירת מחדל המפה מבוססת על OpenStreetMap (חינמי לגמרי, בלי מפתח). אם תרצה מפת Google Maps במקום זאת, Google דורשת מפתח API משלה (יש שכבה חינמית, אך **דורשת כרטיס אשראי** גם אם בפועל לא תשלם):
  1. כנסו ל-**console.cloud.google.com**, צרו פרויקט, והפעילו את ה-API בשם **Maps JavaScript API**.
  2. צרו מפתח API (Credentials → Create Credentials → API key).
  3. הדביקו אותו כ-`GOOGLE_MAPS_API_KEY` בקובץ `.env` שלכם (או ב-Secrets ב-Replit).
  4. אחרי הפעלה מחדש של האפליקציה, המפה בתוצאה, בניווט החי, ובזיהוי הכתובות (כניסיון נוסף) ישתמשו ב-Google אוטומטית. בלי מפתח, הכול ממשיך לעבוד רגיל עם OpenStreetMap.
- **הכוונה קולית בעברית**: הקול עצמו מגיע מהמנוע המובנה של הדפדפן/מערכת ההפעלה שלכם, לא מהשרת. אם אין קול עברי מותקן במכשיר (נדיר, אבל קורה בעיקר בווינדוס ישן או בדפדפנים מסוימים באנדרואיד), ייתכן שישתמש בקול ברירת המחדל שעלול לבטא את הטקסט לא נכון — הפתרון הוא להתקין חבילת שפה עברית ב-Text-to-Speech של המכשיר (בהגדרות המערכת, לא באפליקציה עצמה).

## מגבלות שכדאי לדעת עליהן

- שירותי המפות בהם נעשה שימוש (Nominatim, OSRM) הם שירותים ציבוריים וחינמיים, נוחים מאוד לשימוש אישי של נהג בודד — אבל לא מיועדים לעומס גבוה של עסק עם הרבה נהגים ומשלוחים בו-זמנית. אם תגיע לשימוש בהיקף כזה, המעבר הבא יהיה ל-Google Maps Platform (בתשלום, לפי שימוש), עם מפתח API שמוגדר כמשתנה סביבה (בדיוק כמו `RESEND_API_KEY` למעלה).
- מסד הנתונים כאן הוא קובץ JSON פשוט — מצוין לשימוש אישי או לצוות קטן. אם תרצה יום אחד להרחיב לעשרות נהגים במקביל, שווה לשדרג למסד נתונים אמיתי כמו Postgres (ברוב שירותי האירוח, כולל Render, יש לזה גם שכבה חינמית).
